# Technology Stack

- Vite 8, React 19, TypeScript 6.
- Vike with `vike-react` for static generation and hydration.
- Tailwind CSS 4 and Radix-based local UI primitives.
- `exceljs` for client-side XLSX generation, loaded dynamically.
- Vitest and Testing Library for unit/component tests.
- Playwright for route smoke tests.
- Vercel static deployment from `dist/client`.

No backend, database, authentication, or server-side persistence is required.
