# Engineering Standards

- Keep tax and calendar calculations in pure TypeScript modules.
- Keep UI components free of duplicated tax constants and date rules.
- Use semantic HTML, visible focus styles, keyboard-accessible controls, and
  WCAG 2.2 AA contrast and target-size guidance.
- Format money and dates with `Intl` using the `ru-RU` locale.
- Lazy-load optional export libraries.
- Every public route requires unique metadata, canonical URL, Open Graph tags,
  JSON-LD, and visible explanatory copy.
- Do not commit credentials, verification files, analytics identifiers, or
  private user data.
