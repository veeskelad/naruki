# На руки

Веб-сервис с двумя калькуляторами для работающих в России:

- **Когда брать отпуск** — производственный календарь РФ и подсветка дат, когда отпуск выгоднее по длине отдыха и по деньгам.
- **Сколько придёт на руки** — расчёт зарплаты по месяцам и за год для ТК РФ, самозанятых и ИП.

Все вычисления — в браузере. Никакие данные не отправляются на сервер.

## Стек

- Vite + React + TypeScript
- Tailwind CSS
- Recharts, exceljs

## Разработка

```bash
npm install
npm run dev      # dev-сервер
npm run build    # продакшен-сборка
npm run preview  # локальный просмотр сборки
```

## Структура

- `src/pages/` — страницы маршрутов
- `src/components/vacation/` — компоненты модуля отпуска
- `src/components/salary/` — компоненты калькулятора зарплаты
- `src/lib/` — логика расчётов
- `src/data/` — производственный календарь и налоговые ставки
